# NLP-WITH-DISASTER-TWEETS
# 🧠 Disaster Tweet Classification using Advanced NLP Techniques

This group project implements a machine learning pipeline to classify disaster-related tweets using advanced Natural Language Processing (NLP) techniques such as **LDA for topic modeling**, **temporal feature extraction**, **text augmentation**, and **class imbalance handling using SMOTE**. The final model uses a **Random Forest Classifier** and demonstrates significant improvement in classification accuracy.
